# Frontend Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the Timsies Entirety frontend — install the intended CLAUDE.md tool stack (minus `recharts`) and create a placeholder Header, Footer, and Homepage.

**Architecture:** Standard Vite + React 19 SPA. `App.jsx` owns a single `createBrowserRouter` with one route (`/`) rendering a `Layout` (Header + `<Outlet />` + Footer) whose only child is `Home`. No data fetching, no forms, no backend — installed libraries beyond `react-router-dom` are present in `package.json` but not wired into any component yet.

**Tech Stack:** Vite 7, React 19, Tailwind CSS v4 (`@tailwindcss/vite`), react-router-dom 7, axios, react-hook-form, react-icons, react-tooltip, react-hot-toast, motion, vitest + Testing Library + jsdom.

## Global Constraints

- Frontend only — no `/backend` work, no auth, no admin panel.
- Scaffold into the existing lowercase `frontend/` folder.
- React 19 new JSX transform — never `import React from 'react'` just for JSX.
- Tailwind v4 via `@tailwindcss/vite` only — no `tailwind.config.js`.
- Routes centralized in one `createBrowserRouter` call in `frontend/src/App.jsx` — no loaders/actions, no second `<Routes>` tree.
- Install `react-router-dom`, `axios`, `react-hook-form`, `react-icons`, `react-tooltip`, `react-hot-toast`, `motion` — explicitly **not** `recharts`.
- Installed libraries beyond routing are not wired up yet (no `axiosApi.js`, no mounted `<Toaster />`/`<Tooltip />`) — nothing today needs them.
- No design/styling pass — `ui-ux-pro-max` is deferred to real homepage content work.
- Test stack: `vitest` + Testing Library + `jsdom`, config lives in `vite.config.js` per CLAUDE.md.
- Every component gets a short block comment above it (what it does, props, return) per CLAUDE.md comment rules.
- Package manager: npm.
- Commit after every task.

- [ ] **Step 4: Rewrite App.jsx with the router**

Replace the full contents of `frontend/src/App.jsx` with:

```jsx
import { createBrowserRouter, RouterProvider } from 'react-router-dom'
import Layout from './components/Layout'
import Home from './pages/Home'

// Router: single centralized route table per CLAUDE.md routing convention.
// Every route renders inside Layout; only the homepage exists today.
const router = createBrowserRouter([
  {
    path: '/',
    element: <Layout />,
    children: [{ index: true, element: <Home /> }],
  },
])

// App: root component — hands the router to the rest of the tree.
// Takes no props. Returns the RouterProvider.
function App() {
  return <RouterProvider router={router} />
}

export default App
```
